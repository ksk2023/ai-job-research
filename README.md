# AI 岗位调研数据平台（ai-job-research）

> 覆盖 45 家公司的 AI 岗位抓取、清洗、交叉验证与可视化，附 5 份求职调研报告
> 数据截至 2026-08-14：**895 个在招岗位 · 15 家公司 · 多源交叉验证**

## 📦 仓库内容

| 模块 | 说明 |
|---|---|
| `site/` | 静态展示网站（5 页：首页/岗位列表/详情/公司/下载），原生 HTML + ECharts，无需构建 |
| `scrapers/` | 47 个招聘平台抓取适配器（飞书招聘/北森/Moka/91job/自建系统等 SaaS 共享适配器） |
| `pipeline/` | 数据流水线：清洗 → 分类打标 → 三重筛选 → 交叉验证 |
| `scripts/` | 巏具脚本，含每日全量更新 `daily_update.py` |
| `data/` | 原始/清洗/验证后数据（jsonl 格式），含抓取缓存 |
| `reports/` | 5 份求职调研报告（HTML，浏览器直接打开） |
| `docs/` | 逆向的 15 家大厂招聘 API 端点文档 |
| `companies.json` | 45 家公司抓取配置（大厂/AI 厂商/外企） |

## 🚀 本地运行网站

```bash
cd site
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 📊 数据流水线

```bash
# 安装依赖
pip install -r requirements.txt

# 全量抓取 → 清洗 → 筛选 → 验证 → 重建网站数据
python scripts/daily_update.py

# 断点续跑（跳过抓取，直接跑管道）
python scripts/run_pipeline_only.py
```

### 筛选规则（三重筛选）
1. 仅国内公司（排除 OpenAI/Google 等外企）
2. 仅中国大陆工作地点
3. 研究生及以上学历

### 交叉验证
≥2 个独立来源的岗位标记为「已验证」，单源岗位按置信度评分。
