## 🔍 核心调研结论速览

> 详细数据与来源验证见 [`reports/`](./reports) 下各报告，以下为跨报告汇总的核心结论。

### 1. 薪资：技术岗全面领先

- **秋招总包梯度**：技术岗 35-60W > 产品岗 20-35W > 运营岗 15-24W
- **普适倍数**：技术岗 ≈ 产品岗 ×1.3-1.5 ≈ 运营岗 ×1.5-2；硬件厂（宁德时代 / 比亚迪等）差距最大达 2-4 倍
- **校招天花板**：华为天才少年 201W > DeepSeek 154W（月薪 6W 起 · 14 薪）> 月之暗面 150W > 字节 Top Seed
- **AI 公司全员高薪**：DeepSeek / 智谱 / MiniMax 等非技术岗也接近大厂技术岗水平

### 2. 实习日薪（一手在招数据，已逐条验证）

| 学历 | 技术岗日薪 | 非技术岗日薪 |
| --- | --- | --- |
| 本科 | 120-500 | 100-200 |
| 硕士 | 180-800 | 150-300 |
| 博士 | 350-2000 | — |

- 常规大厂算法岗 300-600/天，AI 独角兽 500-2000/天，顶尖天才计划 4000-8000/天（全国 < 100 人）
- **实习天花板**：阿里 T-Star / 商汤 AI 先锋 2000/天
- 特色政策：腾讯统一 7500/月不分公司、字节 400/天+房补、美团 280/天但转正率 80% 最高

### 3. 笔试 / 刷题要求：分岗位差异极大

- **笔试形态**：大厂普遍 3-4 道编程题；字节最难（40 行测 + 4 编程含 2 道 Hard）；华为 150/600 及格
- **刷题量基准**：开发岗 200-300 道、算法岗 300-400 道（行业平均 370 道）
- **AI 应用开发岗大幅降低**：仅 Easy-Medium，Hot 100 够用——2026 春招 AI Coding 已成新趋势（蚂蚁率先笔试必考）
- **AI 岗必考手撕已变**：Transformer / Self-Attention / RoPE / GQA，取代传统 ML 算法
- 笔试 ACM 模式 vs 面试核心代码模式 差异大，是主要失分点

### 4. 不刷力扣也有出路

- 完全不考算法的岗位：产品经理、运营、数据分析（业务向）、HR、财务、销售、设计、游戏策划、技术支持 / 售前——考行测 + 业务问答 + 群面，**考公党有天然优势**
- **JD 判断法**：出现「数据结构 / 算法 / 编程」→ 可能考；出现「SQL / Excel / PPT / 业务分析」→ 基本不考
- 趋势：AI 能力正成为所有岗位标配（AI 产品经理需求增长 178%）

### 5. 数据抓取洞察（逆向 15+ 家大厂招聘系统后）

- 招聘站点 4 类底层 SaaS：飞书招聘（智谱 / 百川 / MiniMax）、北森（商汤）、Moka（阶跃 / 依图）、自建（腾讯 / 字节 / 百度）
- 腾讯招聘有公开 JSON API 最易获取；字节 / 阿里 / 华为反爬最强
- 详细 API 端点逆向文档见 [`docs/api_endpoints.md`](./docs/api_endpoints.md)

## 📊 数据流水线

```bash
# 安装依赖
pip install -r requirements.txt

# 全量抓取 → 清洗 → 筛选 → 验证 → 重建网站数据
python scripts/daily_update.py

# 断点续跑（跳过抓取，直接跑管道）
python scripts/run_pipeline_only.py
```

### 筛选规则（三重筛选）

1. 仅国内公司（排除 OpenAI / Google 等外企）
2. 仅中国大陆工作地点
3. 研究生及以上学历

### 交叉验证

≥ 2 个独立来源的岗位标记为「已验证」，单源岗位按置信度评分。

## 📁 项目结构

```text
ai-job-research/
├── site/                    # 静态展示网站（5 页：首页/岗位列表/详情/公司/下载）
│                            # 原生 HTML + ECharts，无需构建步骤
├── scrapers/                # 47 个招聘平台抓取适配器
│                            # 覆盖飞书招聘 / 北森 / Moka / 91job / 自建 SaaS
├── pipeline/                # 数据流水线
│                            # 清洗 → 分类打标 → 三重筛选 → 交叉验证
├── scripts/                 # 工具脚本
│                            # 含每日全量更新 daily_update.py
├── data/                    # 原始 / 清洗 / 验证后数据（jsonl，含抓取缓存）
├── reports/                 # 5 份求职调研报告（HTML + Markdown 双格式）
├── docs/                    # 逆向的 15 家大厂招聘 API 端点文档
├── companies.json           # 45 家公司抓取配置（大厂 / AI 厂商 / 外企）
├── requirements.txt         # Python 依赖
└── README.md
```
